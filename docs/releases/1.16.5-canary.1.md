# Forkop X 1.16.5-canary.1

Исправлен отказ запуска обычного и compressed sing-box Extended 1.14 с ошибкой `missing conditions`, когда секция использует наборы с IP-правилами и исключённые устройства без фильтра по устройствам. Генератор больше не добавляет пустое вложенное условие в DNS-правило `evaluate`; исключение устройства сохраняется.

Проверено: регрессионные тесты DNS для sing-box 1.12/1.13/1.14 и тесты runtime; воспроизведение ошибки и успешная проверка исправленной конфигурации обычным и compressed Extended 1.14.1; установка IPK/APK, запуск Forkop и FakeIP DNS на существующих VM OpenWrt 24 и 25.

Этот выпуск не изменяет Tailscale.
