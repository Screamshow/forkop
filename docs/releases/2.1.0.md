## Запуск и перезапуск

- Ускорены запуск и перезапуск Forkop X. Убраны лишние ожидания при отсутствующих модулях, например zapret2.
- Проверка процессов больше не запускает отдельную команду readlink для каждого процесса.
- Убраны повторные определения версии sing-box при подготовке конфигурации и подписок.

## Обновление правил

- Ускорена обработка неизменившихся SRS.

## DNS

- Для поддерживаемых конфигураций dnsmasq полный restart заменён на reload с проверкой применения настроек и готовности DNS.
- При отказе reload или неподдерживаемой конфигурации используется restart.
- Исправлена обработка DNS-запросов в режиме FakeIP. Подмена адресов применяется только к A и AAAA, остальные типы записей обрабатываются обычными DNS-правилами.
- Для списка Discord DNS секции теперь выбирается по домену до получения IP-адреса. Убрано сопоставление DNS-запросов по общим адресам Cloudflare.

## Discord

- Добавлена маршрутизация TCP-соединений на общих адресах Cloudflare по портам медиа-сервисов Discord.

## Sing-Box X

- Добавлено распознавание XHTTP в Sing-Box X 1.0.2. Поддержка определяется по возможностям установленного ядра.
- XHTTP-серверы поддерживаемых подписок больше не требуют установки Extended. Сохранена совместимость с прежними вариантами sing-box.

## Временная поддержка

- Добавлена периодическая проверка связи со стороны роутера во время активной сессии поддержки через Tailscale.
- При недоступности выполняется диагностика соединения и повторная проверка с ограничением частоты.
- Исправлено обновление старых конфигураций.

## Общие изменения

- Уменьшен размер файлов LuCI примерно на 150 КиБ за счёт компактной упаковки JavaScript.
- Проведена чистка кода и убрана обязательная зависимость coreutils-base64. Уже установленный пакет автоматически не удаляется.
