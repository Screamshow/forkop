## Мониторинг соединений

- Для правил с доменами и IP-подсетями мониторинг показывает совпавшие условия вместо всего списка: например, `ws.chatgpt.com → domain_suffix=chatgpt.com`.
- Поддерживаются точные домены, суффиксы, ключевые слова, совместимые регулярные выражения и IPv4/IPv6 CIDR. Если совпало несколько условий, отображаются все найденные совпадения.
- Сокращённые списки из Clash API дополняются условиями из действующей конфигурации sing-box, когда сработавшее правило можно однозначно сопоставить.
- Полное правило доступно в подсказке при наведении. При недостатке данных, неоднозначном сопоставлении, сложном логическом правиле или неподдерживаемом regex сохраняется исходное отображение.
- Изменение работает в LuCI и не требует обновления ядра sing-box. Совпадения вычисляются по данным соединения; ядро не передаёт точный элемент списка.

## Проверка

- 539 тестов интерфейса, проверка TypeScript и линтер прошли.
- На роутере 192.168.90.1 проверены живые соединения и отображение в мониторинге.
- После обновления при сохранении старого отображения требуется обновить страницу с очисткой браузерного кеша.
