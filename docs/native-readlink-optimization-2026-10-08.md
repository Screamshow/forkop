# Проверка и внедрение native readlink — 8 октября 2026

На main в service/state.uc три чтения /proc/PID/exe через внешний readlink заменены на встроенный fs.readlink. Проверки PID, basename executable, deleted executable, procd provenance и start_ticks не убраны и не упрощены.

## Проверки

- Новый tests/native_process_identity.sh проверяет обычный executable, deleted executable, посторонний executable с именем sing-box, несовпадающее имя, пропавший PID и неверный PID.
- Дополнен tests/singbox_single_process.sh: второй тестовый sing-box запускается из временной копии, затем исполняемый файл удаляется; этот процесс должен остаться учтённым и не признаваться принадлежащим рабочему runtime.
- worker_identity, manual_restart_contract, sing_box_runtime, provider_shutdown и sing_box_deleted_identity прошли локально. Последний тест включает контроль повторного использования PID, изменения start_ticks и смены PID procd.
- worker_identity и расширенный singbox_single_process прошли на обеих существующих OpenWrt ВМ с временно установленным state.uc. Проверены второй/чужой процесс, deleted executable, ложный PID procd и сохранение nft policy при отказе reload/restart. Исходный модуль ВМ восстановлен и проверен побайтно.
- Те же интеграционные проверки пройдены на 192.168.90.1. Тесты завершают только собственный второй процесс.

## Полный ручной restart на 192.168.90.1

Для сравнения использован ранее снятый на этом же роутере профиль 43,56 секунды и новый профиль с исправлением 38,68 секунды. Оба выполняют manual_restart с реальной конфигурацией, свежей подготовкой подписок/списков и неизменным восьмисекундным порогом стабильности. Измерены monotonic timestamps /proc/uptime. Это один сравнительный контрольный запуск, не медиана серии и не гарантия времени каждого будущего нажатия кнопки LuCI.

| Этап | Исходный state.uc | fs.readlink |
|---|---:|---:|
| Полный manual restart | 43,56 с | 38,68 с |
| Внутренний restart без подготовки данных | 32,24 с | 27,21 с |
| stop_impl с DNS | 7,06 с | 4,96 с |
| start_impl с DNS | 23,47 с | 21,51 с |
| Проверка конфликта процессов | 0,69–0,72 с | 0,09–0,10 с |
| singbox init-config | 3,81 с | 2,81 с |
| Запуск sing-box и стабильность | 9,46 с | 8,61 с |

Вложенные длительности не складываются с длительностями родителей. Подготовка подписки/списков/rulesets составила 11,03 с раньше и 11,18 с после, то есть основной выигрыш связан с runtime, а не более быстрым скачиванием. Суммарно полный вызов быстрее на 4,88 с (около 11%). Внутренний restart быстрее на 5,03 с.
